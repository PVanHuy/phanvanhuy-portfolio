SOS Connect

Emergency Rescue & Community Support Platform

A mobile application that connects people in emergency situations with nearby volunteers and rescue teams — from SOS reporting to realtime coordination and safe completion.

Role Mobile Developer / Project Developer Platform Android · iOS
Flutter GetX MVVM WebSocket FCM Flutter Map GitHub Actions
View on GitHub

The problem

When an incident happens, people need to quickly share their location and situation with those who can help — nearby volunteers or organized rescue teams.

The solution

SOS Connect lets users send an SOS with location, photos, and incident details. Support forces can find nearby requests, accept missions, navigate to the scene, and coordinate in realtime chat until the person is safe.

Key features

  • SOS emergency reporting
  • Realtime rescue chat
  • Location & map clustering
  • In-app route navigation
  • Push notifications (FCM)
  • Rescue team management
  • SOS status tracking
  • AI assistant & weather info

Technical challenges

  • Realtime communication Implemented Socket.IO-based realtime messaging for SOS coordination and chat scoped by sosId.
  • Map & location Built SOS visualization with OpenStreetMap, map clustering, current location, and OSRM-powered in-app routing.
  • Emergency workflow Designed separate flows for victims and rescue teams — from SOS creation through acceptance to rescue completion.
  • CI/CD Configured GitHub Actions to automate Android APK/AAB builds and prepare signed releases for Google Play.
